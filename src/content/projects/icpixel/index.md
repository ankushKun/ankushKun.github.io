**ICPixel** puts both the pixel-art editor and the public gallery straight onto **Internet Computer (ICP)** canisters, with no separate database or centralized file host required.

## Highlights

- **On-chain backend:** Written in **Motoko** to store and serve community pixel artwork directly from canisters
- **Browser studio:** Built with **React** and **TypeScript** for sketching, sharing, and browsing creations live in the browser
