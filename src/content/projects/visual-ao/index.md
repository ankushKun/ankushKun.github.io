**Visual AO** was a flow-based node editor for assembling, inspecting, and exporting AO processes visually — aimed at making AO's message-passing model easier to learn and prototype before dropping into raw Lua.

## Features

- Drag-and-drop node graph connecting handlers, conditions, and message outputs
- Real-time process inspection and flow export to AO-ready Lua code

> Introducing Visual AO — program your ao processes visually, without needing to write code.
