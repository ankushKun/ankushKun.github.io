`create-magicblock` scaffolds a working MagicBlock application on Solana in seconds, skipping the repetitive Anchor and ephemeral-rollup boilerplate so you can jump straight into building real-time on-chain apps.

Built after wiring up the same setup by hand for [pixels.earth](/projects/pixels-earth/), it ships with sensible project structure and working ephemeral-rollup defaults out of the box and has picked up 1,300+ downloads on npm.

> Scaffold working `@magicblock` dapps in seconds with `create-magicblock`.
