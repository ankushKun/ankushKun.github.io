Co-founded [Construct Computer](https://construct.computer/?utm_source=ankush.one&utm_medium=referral&utm_campaign=timeline) with Nischal Naik in February 2026.

Construct gives every AI employee its own cloud computer — browser, terminal, files, email, and memory — so agents can finish work end to end rather than stopping at a chat box. The first desktop build was running a week later, and the waitlist opened at the start of March. More on the [project page](/projects/construct-computer/).
