**Frustrated by subscription-wall photo editors on iOS, I built my own.**

Power Editor provides professional-grade tools like curves, HSL, and filters completely for free. Built in a single weekend.

## 🎨 Key Features
- **Advanced Tools:** Curves, HSL adjustments, and selective color grading.
- **Privacy Focused:** All processing happens on-device.
- **No Subscriptions:** 100% free and open source.

## 🍏 Tech Stack
- **Swift / SwiftUI**
- **CoreImage** for GPU-accelerated processing.
