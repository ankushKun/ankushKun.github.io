**x402bay is a decentralized marketplace built on the x402 protocol, enabling censorship-resistant commerce on the Permaweb.**

It serves as a reference implementation for the x402 protocol, demonstrating how to build robust e-commerce experiences on Arweave.

## 🛍️ Features
- **Decentralized Listings:** Items are stored permanently on Arweave.
- **Trustless Transactions:** Smart contracts ensure safe buying and selling.
- **x402 Protocol:** Leverages the Universal Data License and monetization standards.

## 🔧 Tech Stack
- **Arweave** for storage.
- **React** for the frontend.
- **x402 Protocol** for commerce logic.
