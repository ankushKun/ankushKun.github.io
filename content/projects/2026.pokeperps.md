TradeX (it started life as PokePerps) let you go long or short on Pokemon card prices with up to 20x leverage. Prices were scraped from TCGPlayer every 30 seconds and published on-chain via a keeper oracle. All trading was non-custodial, with positions, margin and settlement handled entirely by the on-chain program.

I renamed it TradeX on 22 February 2026, moved it to tradex.cards and its own GitHub org, and redeployed the program to a fresh mainnet address the next day. An independent auditor, calc1f4r, then spent about eight days on the whole Solana program and found 1 high, 5 medium and 6 low severity issues. I fixed all of them on 4 March, with one follow-up the next day, and cut max leverage from 50x to 20x at the same time. The [audit report](https://tradex.cards/audit-032026.pdf) is public.

I stopped working on it in March 2026 and the backend is offline now, so you can no longer trade on it. The program, the audit and the write-up below are what's left.

## How It Works

```text
TCGPlayer.com                    Solana Blockchain
(card prices)                    (settlement layer)
      |                                |
      | scrape every 30s               |
      v                                v
+----------+    publish prices    +--------------+
| Backend  | ------------------> |   On-Chain   |
| (Elysia) |                     |   Program    |
|          | <------------------ |              |
|          |    read state       | (positions)  |
+----+-----+                     +--------------+
     | REST + WebSocket                 ^
     v                                  | sign txs
+----------+                            |
| Frontend | ---------------------------+
| (React)  |   Phantom wallet
+----------+
```

The backend scraped TCGPlayer marketplace data and published price updates on-chain. The Solana program (Rust + [Pinocchio](https://github.com/anza-xyz/pinocchio)) handled all the trading logic: opening and closing positions, margin calculations, liquidations and settlement. The frontend connected through Phantom for signing.

## AI Agent Integration

TradeX shipped an [MCP server](https://www.npmjs.com/package/@tradexcards/mcp) so Claude and other AI agents could trade programmatically. It was set up like this (it won't work now that the backend is gone):

```bash
# Claude Code (read-only)
claude mcp add tradex -- npx -y @tradexcards/mcp

# With trade execution
claude mcp add tradex -e TRADEX_KEYPAIR=/path/to/keypair.json -- npx -y @tradexcards/mcp
```

There was also a [SKILL.md](https://tradex.cards/SKILL.md) and an [llms.txt](https://tradex.cards/llms.txt) for agents that preferred fetching instructions directly.

| **Runtime**          | Bun                                |
| **AI integration**   | MCP server (`@tradexcards/mcp`)    |
