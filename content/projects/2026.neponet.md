**Everything great starts with a friend of a friend of a friend.**

NepoNet (Nepotism Network on Product Hunt) finds you a warm intro to anyone on X. Give it a person and it looks for chains like you, then a friend, then a friend of theirs, then the person you want to reach, where everyone already follows the one before them. It reads public follow lists, scores every route for warmth from 0 to 100, explains each hop, drafts the message for the first person, and tells you who to get closer to first.

It never sends anything on your behalf, so you stay in charge of every ask.

We built it at Construct after our own Product Hunt launch, where the intros that mattered all came through friends of friends and finding those chains by hand took weeks of scrolling through follower lists.

## Features
- Ranked routes to anyone on X, with a short explanation for every hop
- A drafted first message for each route
- A Plan tab that researches everyone on a route and writes a plan with drafts
- An Outreach board to keep track of who you've asked
- Bring your own AI through OpenRouter or your own key

## Built for agents too
NepoNet has a remote MCP server with OAuth, an HTTP tools API with an OpenAPI spec, an llms.txt and an installable Agent Skill, so Claude Code, Codex, Cursor and friends can find intros the same way people do in the app.

## Stack
A TypeScript monorepo on Cloudflare. The API is Hono and SQLite behind a Worker, and the web app is React with the route drawn on a canvas. During launch week the follow graph outgrew its Durable Object, so the API moved onto our own server, still behind the same Worker.

I built it with Vibhansh Alok, who did the design. It's free to start, and Premium is $6.99 a month for 100 searches a day.
